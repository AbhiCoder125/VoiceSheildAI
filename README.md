# VoiceSheildAI
Prototype for SIH

## Member 5 - Security & Context Analysis

- Developed voice-cloning threat scenarios and realistic attack cases.
- Defined security context factors such as caller identity, claimed identity, request type, transaction amount, urgency, and sensitive information.
- Designed the security decision workflow:
  - LOW -> ALLOW
  - MEDIUM -> WARN
  - HIGH -> SECONDARY VERIFICATION
  - CRITICAL -> BLOCK / ESCALATE
- Defined prevention rules for synthetic voice, impersonation, financial fraud, OTP, password, PIN, and sensitive-information attacks.
- Documented privacy and security requirements.
- Added explainability requirements for security decisions.
- Prepared security validation scenarios for integration with the Group 2 risk engine.
